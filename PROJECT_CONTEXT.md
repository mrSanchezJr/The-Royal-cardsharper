# PROJECT CONTEXT: The Royal Cardshaper (Королевский Картошлёп)

> **Краткое описание**: Однопользовательская сюжетная карточная игра в жанре «Дурак» с уникальной механикой шулерства («Ловкость рук»), процедурной векторной графикой и королевским средневековым сеттингом. Игра разработана в виде автономного исполняемого файла под Windows x64 с жестким лимитом размера дискеты 1.44 МБ (фактический размер ~1.33 МБ без UPX — за счёт кастомной slim-сборки raylib без rmodels и oxipng-оптимизации спрайтов).

---

## 1. Стек технологий

* **Язык программирования**: C (стандарт C99).
* **Графическая библиотека**: [Raylib](https://www.raylib.com/) (статическая сборка, без внешних DLL).
* **Сборщик / Компилятор**: GCC (MinGW-w64 x86_64, w64devkit) с оптимизациями `-Os`, `-s`, `-static`, `-Wall`, `-fno-unwind-tables`, `-fno-stack-protector`.
* **Сборка raylib**: Кастомная минимальная сборка из исходников `C:\raylib\raylib\src` (v6.0) с отключёнными `SUPPORT_MODULE_RMODELS` (3D-модули), неиспользуемыми форматами файлов (BMP, DDS, OBJ, MTL, IQM, GLTF, VOX, M3D) и аудиокодеками (OGG, XM, MOD). Позволяет уложиться в 1.44 МБ **без UPX** (нет ложных срабатываний Windows Defender). Важно: **не** используется флаг `-DEXTERNAL_CONFIG_FLAGS`, чтобы `config.h` обеспечивал дефолты для PNG/TTF/WAV/MP3.
* **Оптимизация PNG**: [oxipng](https://github.com/shssoichiro/oxipng) v9 (`--opt max --strip all`) — лосслесс-сжатие встроенных спрайтов (~33% экономии).
* **Система сборки**: Пакетный скрипт `build.bat` (канонический): компилирует slim raylib из исходников + линкует игру. `CMakeLists.txt` (альтернативный).
* **Целевая платформа**: Windows 7/10/11 x64 (Standalone `.exe`, без сторонних установщиков и рантаймов).
* **Шрифтовая подсистема**: Системные serif-шрифты Windows (`Georgia`, `Cambria`, `Palatino Linotype`, `Segoe UI`, `Arial`) с билинейной фильтрацией и базовым разрешением 32px; основной шрифт + символьный `Segoe UI Symbol` для масти, стрелок и тире (U+2013/2014); полная поддержка кириллицы и латиницы.
* **Аудио-подсистема**: Полностью процедурный синтез (без аудиофайлов): музыкальный луп (10-секундный средневековый цикл Am–F–C–G с арпеджио и пентатоникой) и 5 SFX (`SFX_CARD_PLAY`, `SFX_CARD_TAKE`, `SFX_CHEAT_SWAP`, `SFX_CAUGHT`, `SFX_ROUND_END`) генерируются в памяти при запуске (`src/audio.c`), воспроизведение через Raylib Audio (miniaudio/WASAPI). Громкости Music/SFX (0–10) настраиваются в меню и хранятся в `save.ini`.

> **ВАЖНО (сборка)**: `build.bat` компилирует **кастомную slim-сборку raylib** напрямую из исходников `C:\raylib\raylib\src` (v6.0) с отключённым `SUPPORT_MODULE_RMODELS` и неиспользуемыми форматами. Это позволяет обойтись **без UPX** (Windows Defender детектировал UPX как малварь). Готовая `C:\raylib\w64devkit\lib\libraylib.a` **не используется**. Заголовки raylib берутся из `C:\raylib\raylib\src`, а не из `C:\raylib\w64devkit\include`.

## 2. Архитектура проекта

Кодовая база разделена на независимые модули с четким разграничением ответственности:

```
The royal cardshaper/
├── src/
│   ├── main.c           # Главный цикл, машина состояний (AppState), обработка ввода
│   ├── game_logic.h/.c  # Правила карточной игры «Дурак», колода, фазы, детерминированное обучение
│   ├── ai.h/.c          # Поведение Короля: тайминги отворачивания, отвлечения и 3 уровня сложности навыка игры
│   ├── render.h/.c      # Процедурная отрисовка карт, мастей, персонажей, анимаций и интерфейса
│   ├── audio.h/.c       # Процедурный синтез музыки и SFX (без аудиофайлов), громкости
│   ├── story.h/.c       # Централизованная локализация (RU/EN), диалоги, реплики, отвлечения и обучение
│   ├── save_system.h/.c # Сохранение прогресса, языка и настроек в save.ini
│   ├── characters/      # PNG-спрайты Короля (king_idle/angry/overwhelmed/turned_head)
│   ├── sprites/         # PNG-спрайт стола (table.png)
│   ├── king_*_state.h   # Сгенерированные заголовки спрайтов (xxd -i, не коммитятся)
│   └── table_sprite.h   # Сгенерированный заголовок стола (xxd -i)
├── build.bat            # Скрипт сборки: slim raylib + компиляция игры (без UPX)
├── build/               # Промежуточные .o файлы и libraylib_slim.a (не коммитятся)
├── CMakeLists.txt       # CMake-сборка (альтернативная)
├── save.ini             # Файл локальных сохранений (генерируется автоматически)
└── TheRoyalCardshaper.exe # Готовый бинарник (~1.33 МБ, без упаковщика)
```

### Модули подробно:

1. **`src/main.c` (State Machine & Controller)**
   * Управляет жизненным циклом приложения и состояниями `AppState`:
     * `STATE_LANG_SELECT` — первоначальный выбор языка (Русский / English).
     * `STATE_MENU` — главное меню (Продолжить, Новая игра, Обучение, Доп. настройки, Об авторах, Выход).
     * `STATE_SETTINGS` — настройка сложности ИИ, языка, разрешения окна и громкостей Music/SFX (0–10).
     * `STATE_INTRO_DIALOGUE` & `STATE_INTRO_QUESTION` — завязка истории и предложение пройти обучение.
     * `STATE_TUTORIAL` — интерактивный обучающий матч из 8 этапов с защитой от софтлоков (диалоговое окно на y=332).
     * `STATE_GAME` — основной игровой цикл матчей против Короля (3 партии до финала); в углу `ESC — выход` / `ESC to Exit`.
     * `STATE_CAUGHT` — экран поимки на жульничестве при прямом взгляде Короля (красный оверлей, диалоговое окно на y=500).
     * `STATE_EPILOGUE` & `STATE_CREDITS` — концовка истории и титры (диалоговое окно на y=500).
   * Диалоговые окна интро/эпилога/поимки опущены ниже (y=500), туториальное — выше (y=332), чтобы не перекрывать Короля.
   * Подсказка шулерства (`CHEAT_PROMPT`: «Нажми E...») перенесена в левый верхний угол (30, 90) с миганием.
   * Подсказки 1-го уровня (Партия 1, `matches_won == 0`): бейджи `HINT_BEST_MOVE`/`HINT_TRUMP`/`HINT_TOSS` + баннеры `DrawHintBanner`; эндшпиль-правило — см. ниже. Бейджи `HINT_TOSS` скрываются когда лимит подкидывания достигнут.
   * Контролирует глобальный перехват клавиши `ESC` с модальным подтверждением выхода.

2. **`src/game_logic.h` / `src/game_logic.c` (Core Card Engine)**
   * Модель классической колоды на 36 карт (ранги от 6 до Туза, 4 масти).
   * Реализация правил подкидного «Дурака»: проверка валидности атаки (`CanAttack`), защиты (`CanDefend`), козырей и побития.
   * **Правило лимита подкидывания**: `PlayerAttack` проверяет, что число атакующих карт на столе не превышает количество карт у защищающегося (AI) на начало раунда (`текущие_в_руке + уже_сыгранные_в_защиту`). Аналогичная проверка в `AITakeTurn` для атаки AI.
   * `SetupTutorialGame`: специальная фиксированная раскладка для 100% проходимости обучения.
   * `PlayerCheatSpecific`: подмена выбранной карты руки на СЛУЧАЙНУЮ карту колоды (старая карта прячется на её место); козырь (нижняя карта, index 0) исключён из подмены.
   * `PlayerCheatTop`: детерминированный вариант для туториала — обмен с верхней картой колоды (гарантированная Дама козырей на шаге 6).

3. **`src/ai.h` / `src/ai.c` (King AI & Sleight-of-Hand Timers)**
   * **Детерминированные тайминги отворачивания Короля** (не зависят от сложности карт):
     * *1-й уровень (Матч 1)*: Король всегда отворачивается ровно на **3.5 секунды** (без фальшивых взглядов).
     * *2-й уровень (Матч 2)*: Чередование: **1.0 сек / 3.5 сек / 1.0 сек / 3.5 сек...**
     * *3-й уровень (Матч 3)*: Паттерн: **1.0 сек / 1.0 сек / 3.5 сек...** (каждый 3-й отворот — длинный).
   * **Отвлечения** (`distraction_index`): при каждом отвороте выбирается случайная реплика из пула 6 персонажей (Слуга/Придворный/Гонец/Казначей/Повар/Музыкант) через `GetDistractionText`; в туториале (шаг 6) фиксирован Музыкант.
   * **Сложность игры картами (`card_skill`)**:
     * *Easy (Лёгкий)*: мягкая игра, ИИ не заваливает кучей карт (после 1 успешного отбоя завершает раунд).
     * *Medium (Средний)*: стандартная взвешенная логика (подкидывает до 2 карт).
     * *Hard (Сложный)*: агрессивное подкидывание всех доступных рангов и сохранение козырей.
   * **Лимит подкидывания**: на всех уровнях сложности AI не может подкинуть больше карт, чем было у защищающегося (игрока) в начале раунда (`текущие_в_руке + уже_отбитые`).

4. **`src/render.h` / `src/render.c` (Visuals & Audio-Visual Presentation)**
   * Процедурные векторные значки мастей (Черви, Бубны, Трефы, Пики) без растровых текстур.
   * Карты масштаба `80x118 px` с королевскими эмблемами (Корона, Тиара, Щит для К, Д, В) и двойными индексами.
   * Анимированная рука шулера (`DrawReachingArm`), тянущаяся к колоде, и баннер подмены карт (`DrawSwapNotification`: окно 330x172, карты 74x109, короткая золотая стрелка-фигура).
   * **Королевская дизайн-система**: `DrawRoyalPanel` (тёмный фон + двойная золотая окантовка, ромбы по углам, блик), `DrawTitleFlourish` (орнамент), `DrawHintBanner` (пульсирующий баннер подсказок), `DrawDiamond` (экспортируется), палитра `ROYAL_PARCHMENT`/`ROYAL_PANEL_BG`/`ROYAL_GOLD`.
   * **Фон меню** (`DrawMenuBackground`): процедурный бархатный градиент, золотое свечение за заголовком, ромбовидная решётка, полупрозрачные масти по углам, двойная рамка и виньетка. Применяется на `STATE_LANG_SELECT`/`STATE_MENU`/`STATE_SETTINGS`/`STATE_CREDITS`; стол (`DrawTableTexture` + виньетка) — только в игре/туториале/интро-вопросе.
   * **Левая панель козыря/колоды**: `DrawRoyalPanel` 202x302 с заголовком «КОЗЫРЬ»/«TRUMP», названием масти цветом масти, картами козыря и колоды, чипом счётчика колоды (`DECK_CHIP_FMT`).
   * Контекстные парящие бейджи подсказок для новичков в 1-м уровне (`DrawCardHintBadge`) и чипы статуса хода (`YOUR_TURN`/`DEFEND_TURN` с ромбом).
   * **Спрайтовый Король** (`KingState`) — четыре PNG встроены в бинарник через `xxd -i`:
     * `KING_STATE_IDLE` — `king_idle_state.png` (обычная игра, интро, туториал).
     * `KING_STATE_TURNED` — `king_turned_head.png` (отворот Короля — открыто окно для шулерства, приоритет над IDLE).
     * `KING_STATE_ANGRY` — `king_angry_state.png` (поймали на жульничестве, `STATE_CAUGHT`).
     * `KING_STATE_OVERWHELMED` — `king_overwhelmed_state.png` (игрок выиграл партию).
   * `InitKingSprites()` / `UnloadKingSprites()` — загрузка 4 текстур из памяти через `LoadImageFromMemory`.
   * Шрифты: основной + символьный `Segoe UI Symbol`; хелпер `IsSymbolCodepoint`.

5. **`src/story.h` / `src/story.c` (Complete Localization)**
   * **100% текста вынесено в один файл**:
     * Полная поддержка двух языков: `LANG_RU` (Русский) и `LANG_EN` (English).
     * Тексты меню, кнопок, диалогов, титров, реплик короля на события матча.
     * Пул отвлечений: `GetDistractionCount()` / `GetDistractionText(index, lang)` — 6 вариантов.
     * Ключи UI: `ESC_EXIT_HINT`, `TRUMP_HEADER`, `DECK_CHIP_FMT`, `MUSIC_VOL_FMT`, `SFX_VOL_FMT` и др.
     * Детальные всплывающие подсказки о причинах невозможности хода.
     * Утилита эффекта печатной машинки (`TypewriterText`).

6. **`src/save_system.h` / `src/save_system.c` (Persistence)**
   * Простое и надежное хранение параметров в `save.ini`:
     * `matches_won` (0..3)
     * `tutorial_completed` (0/1)
     * `language` (0: RU, 1: EN)
     * `first_launch_done` (0/1)
     * `ai_difficulty` (0: Easy, 1: Medium, 2: Hard)
     * `window_resolution` (0..5)
     * `music_volume` (0..10, по умолчанию 7)
     * `sfx_volume` (0..10, по умолчанию 7)

7. **`src/audio.h` / `src/audio.c` (Procedural Audio)**
   * Процедурный синтез 5 SFX и 10-секундного музыкального лупа (22050 Hz, mono, 16-bit WAV в памяти).
   * `InitGameAudio` / `UpdateGameAudio` / `CloseGameAudio` / `ApplyAudioVolumes` / `PlayGameSfx`.
   * События: ход картой, взятие карт, подмена, поимка, конец раунда (БИТО).

## 3. Текущее состояние проекта

* **Статус**: Стабильная, полностью рабочая и протестированная версия.
* **Размер бинарника**: ~1.33 МБ (без UPX, за счёт slim-сборки raylib + oxipng-оптимизации спрайтов; при жестком ограничении в 1.44 МБ, запас ~110 КБ).
* **Языки**: Русский и Английский (переключение в меню настроек и при первом запуске).
* **Обучение**: 8 интерактивных шагов с детерминированной раскладкой и проверками от софтлоков.
* **Аудио**: Процедурная музыка + 5 SFX, громкости 0–10 в настройках.
* **Визуал меню**: Королевская дизайн-система — панели с золотыми ромбами, орнаменты, бархатный фон меню с виньеткой; стол — только в игре.
* **Король**: 4 состояния, включая `KING_STATE_TURNED` (голова отвернута) во время окна для шулерства; отвлечения через `SpeechBubble` (6 персонажей).
* **Правила классического дурака**: реализовано ограничение подкидывания — нельзя подкинуть больше карт, чем было у защищающегося в начале раунда. Действует и для игрока, и для AI, подсказки `HINT_TOSS` корректно скрываются при достижении лимита.
* **Подсказки для новичков в Партии 1**:
  * Бейджи над картами: «Лучший ход», «Козырь», «Подкинуть!», «Отбиться!».
  * Баннеры `DrawHintBanner`: «Биться нечем! Нажмите ENTER, чтобы забрать карты» и «Подкинуть нечего! Нажмите ENTER для БИТО».
  * Эндшпиль-правило: когда колода пуста и у Короля меньше карт, чем у игрока — «Лучший ход» = карта, которую Король не сможет отбить (приоритет некозырной).
  * Чипы статуса хода и подсказка шулерства слева вверху с миганием.
* **Шулерство**: Механика выбора конкретной карты по кнопке `E` с анимацией руки и окном подмены 330x172 (карты 74x109, короткая стрелка-фигура); хелпер `KingCanBeatCard()`.
* **Интерфейс**: Левая панель козыря/колоды (чип «В колоде: N»), подсказка `ESC — выход` / `ESC to Exit` в левом верхнем углу игры.

## 4. Следующие потенциальные задачи (Roadmap)

1. **Звуковое сопровождение и SFX** — реализовано (процедурный синтез, см. audio.c)
2. **Визуальные сочные эффекты (Juice & Polish)** — частично реализовано (королевские панели, фон меню, анимация руки):
   * Плавная интерполяция (lerp/easing) перемещения карт из руки на стол и в бито.
   * Легкое покачивание карт при наведении мыши.
   * Частицы золотой пыли при победе над Королем.
3. **Расширение арсенала шулерских приемов**:
   * Возможность подсмотреть следующую карту в колоде («Срезка»).
   * «Туз в рукаве» — сохранение одной скрытой карты в запасной слот с риском обнаружения при обыске.
4. **Новые оппоненты и режимы**:
   * Кампания с новыми соперниками перед Королем (Шут-трикстер, Казначей, Принцесса).
   * Бесконечный режим на выживание («Трактирный турнир»).
5. **Дополнительные языки**:
   * Добавление немецкого, испанского или французского языков через расширение словаря в `src/story.c`.
